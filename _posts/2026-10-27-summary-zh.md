### [苹果 Safari 屏蔽身份解析供应商：早期影响与行业转向](https://digiday.com/marketing/in-graphic-detail-what-apples-identity-block-means-for-the-ad-money/?utm_campaign=digidaydis&amp;utm_medium=rss&amp;utm_source=general-rss) ⭐️ 8.0/10

Digiday 报道，苹果在最新 iPhone 系统更新后于 Safari（含所有基于 WebKit 的浏览器）屏蔽了 UID 2.0、ID5、LiveRamp、Permutive、Audigent 等身份解析（identity resolution）供应商，并一度误伤 The Trade Desk 的广告服务器（10 月初部分恢复）。苹果 10 月 19 日在博客中确认此举针对基于邮箱等登录数据的跨站身份识别。早期数据显示出价率与 eCPM 已出现下滑。

rss · Marketing – Digiday · 10月27日 04:01

**「机制」** 苹果的拦截对象是身份解析公司：这些厂商通过邮箱、电话、IP、设备指纹等碎片信号拼接用户身份，实现跨站跨设备识别，苹果特别针对登录场景收集的邮箱。被切断后，买家在这些流量上可识别的用户减少，出价意愿下降。据 Aditude 数据，WebKit 流量占展示量约 30%、收入 28.5%；更新落地后，iOS 出价率一度下跌 14%（后回升至约-8%），Mac 出价率跌约 25%且未恢复，iOS 与 Mac 的 eCPM 分别下跌 4%和 11%，单次广告机会收入下降 6%和 20%。结构性转向方面，OpenX 数据显示美国买家在第三方受众数据上的支出占比从 2022 年的 78%降至 2025 年的约 40%，上下文定向（contextual targeting，尤其受 CTV 按节目、类型、评级购买的带动）升至约 35%。被屏蔽的 Permutive 则给出自利性较强的数据：无 ID 库存较 Chrome 折价 42%，但 ID 仅覆盖约 30%的出价流；其声称 80 多家出版商应用第一方数据后，直销 CPM 提升 76%、PMP 提升 32%。背景上，eMarketer 预计苹果美国广告收入 2026 年达 90.5 亿美元并持续增长，而服务业务占苹果增长利润的比重已从 2018 年的 24%升至 43%（Enders Analysis），引发行业对苹果既当裁判又当运动员的猜疑。

**「启示」** 浏览器厂商单方面切断身份信号会直接改变拍卖参与度和出价密度，平台与算法工程师需面对可寻址流量进一步碎片化、WebKit 流量价值重估的现实。文章也留下开放问题：早期影响数据来自单一供应商、且身份信号缺口究竟会由上下文与第一方数据补上，还是成为苹果自有广告业务的顺风，目前尚无定论。

## LLM 与 Agent

<a id="item-ai-agentic-1"></a>
### [Anthropic 谈 Opus 5.5 发布与 Managed Agents 的脑手分离架构](https://latent.space/p/opus55/) ⭐️ 8.0/10

Latent Space 访谈 Anthropic 工程负责人 Katelyn Lesse 与产品负责人 Angela Jiang，复盘 Opus 5.5 的发布（更少冗余输出、单位智能成本更低）及其背后的平台工程。核心内容是 Managed Agents 的架构思路：将持久化的 agent harness（大脑）与按需创建的执行沙箱（双手）分离，并分享了 eval、记忆与多智能体设计的实践经验。

rss · Latent Space · 10月27日 18:53

**「要点」** 脑手分离：harness 与会话日志持久存在，沙箱仅在有代码要执行时创建，沙箱崩溃不会拖垮整个 agent 会话；早期把整个编码 agent 塞进沙箱、置于 API 之后，导致首响应延迟高、沙箱消失即 agent 死亡，拆分后延迟与可靠性均改善。安全上，沙箱从不直接持有服务凭证，凭证由代理附加，配合网络出口控制——沙箱里没有凭证，生成的代码就无从读取。记忆功能 Dreaming 的实现很朴素：一个 agent 检查另一个 agent 的历史工作并写回记忆，是复用底层原语搭出高层行为的范例。Eval 方面，他们认为最常见错误是投入不足：需要较大规模的 eval 套件而非少数“完美集合”，从简单做起，把工程当研究——先定目标、形式化为 eval、再定位失败原因（可能是 eval 错、环境错或模型错），且 Claude 本身擅长为 agent 生成评测。多智能体建议只有两条：任务可并行且子 agent 共享统一上下文，子 agent 异步互不阻塞。其他细节：保留 thinking blocks 跨轮传递以防推理被蒸馏提取（但可能破坏客户现有 harness）；早期访问客户在自己 harness 中跑评测比 benchmark 分数更有价值；CPU/沙箱供给与 GPU 一样成为瓶颈；Messages API 已用 Rust 重写。

**「启示」** 设计 agent 运行时先问三个问题：哪些组件必须持久存活、哪些负责执行不可信代码、哪些密钥真的需要出现在代码运行处。同时尽早建 eval 套件，并按“单一 lead + 任务可并行 + 共享状态 + 异步子 agent”的原则尝试多智能体架构。

**标签**: `#Claude`, `#Anthropic`, `#agent workflow`, `#sandboxing`, `#evals`

<a id="item-ai-agentic-2"></a>
### [离线运行 OpenCode 编程 Agent 的完整实践](https://latent.space/p/offline-coding/) ⭐️ 8.0/10

作者在喜马拉雅山区断网环境下实测：用 OpenCode 1.19.4 搭配 Ollama 本地运行 Qwen3.5 9B，全程断网完成了一个经测试验证的一行 bug 修复。文章给出完整配置、命令与避坑建议，并坦承更复杂的两个练习尚未完成。

rss · Latent Space · 10月27日 14:41

**「要点」** 架构分工：OpenCode 负责与项目交互（读文件、提议编辑、跑测试），Ollama 以 OLLAMA\_HOST=127.0.0.1:11434、OLLAMA\_NO\_CLOUD=1、OLLAMA\_CONTEXT\_LENGTH=65536 在本地托管 Qwen3.5 9B（下载约 6.6–7.6 GB，Voltti 建议预留 12–16 GB 内存）；opencode.json 将 model 与 small\_model 都指向该本地模型、baseURL 指向 127.0.0.1:11434/v1，禁用 web 工具并对编辑和 shell 命令要求人工确认。流程：联网时先完整跑通一次（ollama pull qwen3.5:9b、opencode --pure 启动、诊断性提问），然后关 Wi-Fi，用 curl 验证本地 API 通、外网失败，再让 agent 修复 expense\_total.py 中 total = Decimal\(amount\) 应为 += 的 bug，退出后自己跑 python3 -m unittest -v 确认三个失败用例转绿、测试文件未改动。选型参考：Qwen 模型卡中 9B 的 LiveCodeBench v6 为 65.6、BFCL-V4 为 66.1，优于 4B（55.8/50.3）；另引预印本研究称 OpenCode 在 Terminal-Bench Pro 上与 Goose、OpenHands-SDK 通过率接近但 token 消耗约为 Goose 的 40 倍。教训：agent 最初误用 pytest（项目用 unittest），应在提示词中写明确切测试命令；任务要小、保留原始测试、关注内存压力。

**「启示」** 本地小模型 + 权限确认 + 原有测试的组合，足以在断网时完成小型、自包含的编码任务，关键是联网时就把模型、依赖和配置全部备好。但对大型仓库或陌生框架的能力仍未验证，建议从单行修复这类任务起步并自行复跑测试。

## 经济观察

<a id="item-economics-1"></a>
### [Doctorow：未来由人塑造而非注定](https://pluralistic.net/2026/10/27/tied-to-the-tracks/) ⭐️ 7.0/10

Cory Doctorow 在这篇博客中反驳技术与社会未来已被市场或科技决定、人只能被动接受的“必然论”（inevitabilism），主张历史是人做出来的，技术以何种方式进入社会是政治选择而非经济铁律。他同时批评预测市场（prediction markets）和“用钱包投票”的消费主义是宿命论的产物，实际服务于寡头的利益。

rss · Pluralistic: Daily links from Cory Doctorow · 10月27日 09:08

**「观点」** Doctorow 立场鲜明：他憎恶“必然论”，称其为撒切尔主义“别无选择”（there is no alternative）的粗俗版本，并认为“预测未来”本身就是软弱无力的活动，是自认无法改变现实者的迷信。他自称为行动主义者，强调科幻的职责不是预言，而是展示人类可以“夺过方向盘、脱离轨道”。他对预测市场的批判尤为尖锐，视其为内部人操纵、向寡头输送金钱的骗局；对“用钱包投票”则断言其无效，因为亿万富翁的钱包比普通人更厚。

**「论证逻辑」** Doctorow 的论证分几步：其一，科幻作为预测文学是彻底失败的——超过 99.9%的“未来地图”描绘的疆域从未出现，所谓“言中的预言”只是幸存者偏差，如同朝谷仓墙上乱开枪后再画靶心。其二，AI 以当前破坏气候、摧毁就业的方式出现，并非“别无选择”的必然结果——他设想一种替代路径：由 IPCC 与国家实验室联合开发、以改进气候模型为目的、衍生出低能耗开源工具的“AI”，说明技术走向是政治抉择。其三，必然论否定“社会”的存在，把改变归结为马斯克、扎克伯格式的“伟人”，从而否认工会、群众运动和街头的政治意义。其四，预测市场和“用钱包投票”让自认“历史囚徒”的人下注赌未来的苦难，而寡头既能操纵赔率（例如先押注战争再发动战争），又借此从普通人身上获利。他的结论化用科幻桥段：如果抵抗真的无用，征服者就不必宣称“抵抗是徒劳的”——“别无选择”的真实含义是“停止想象其他选择”。

**「概念解释」** 文中“必然论”（inevitabilism）指科技从业者和政策制定者声称未来不可改变、只能适应的主张；“用钱包投票”（vote with your wallet）指用消费选择代替政治组织来推动改变的做法，Doctorow 认为金钱的不平等注定了这场“选举”的输赢；预测市场（prediction markets）号称让人们把信息注入市场，但他称其为被操纵的系统，把日常“投资者”的钱转移给内部人。三者共同构成一种宿命论生态：先让人相信未来已定，再把这种信念变现。

**标签**: `#technological determinism`, `#prediction markets`, `#market ideology`, `#political economy`, `#science fiction`
